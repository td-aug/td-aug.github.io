# TD-Aug Website

Static project page for **Imagining Goals with Geometric Horizon Models for Policy Generalization**.

No build step or package installation is required. For GitHub Pages, serve the
repository root.

Open `index.html` in a browser, or preview locally:

```bash
python serve.py
```

Edit `index.html` for content and `static/css/style.css` for styling.
The layout follows the simple paper-page format of `self-pred-bc.github.io`.

Figures and tables come from the October 6, 2026 paper draft. The Paper link
points to OpenReview; no full paper PDF is hosted here.

Results videos use the October 12 exports. Selected source episodes are recorded
in `static/videos/sources.json`; playback retains the original frames and timing.
